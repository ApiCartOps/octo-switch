How it routes

The right token, every call.

1
An explicit account
The agent passes account by name or GitHub login
2
The repo owner
ApiCartOps/demo uses the account whose login is ApiCartOps
3
Your default account
Used when nothing else matches

Accounts are stored locally, and one is picked per call.

Set up

Set up in minutes.

# tokens are typed at a hidden prompt npm install -g octoswitch octoswitch add personal --default octoswitch add work octoswitch install claude-code

install merges one entry into your agent's MCP config and leaves the rest of the file alone.
